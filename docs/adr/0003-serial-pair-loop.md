# ADR-0003：`symbol × job` 保持串行循环

## 状态

已接受。

## 背景

一个符号可能有几十个 job，每个 job 有几千个文件。看似可以并行处理多个 pair，
但两条语义依赖这个顺序：

1. **404 阈值**按整轮请求的比率判断；并行 pair 会让“窗口内样本”随调度顺序变化。
2. **熔断器**统计连续失败；并行 pair 无法定义“连续”，也无法在故障时及时停下。

## 决策

1. 外层 `symbol`、内层 `job` 串行。
2. 单个 pair 内部按 `concurrency` 并发下载文件。
3. 取消检查放在 pair 边界，Ctrl-C 不启动下一个 pair。
4. 连续 5 个 pair 失败即熔断。

## 后果

- 吞吐上限由单 pair 的并发决定；datasets 多时总时长线性增长。
- 404 比率与熔断语义稳定、可测试。
- 未来若要并行 pair，需要先重新设计阈值与熔断的统计单位。
